# 터무늬 부동산 인텔리전스 — 아산시 부동산 빅데이터 대시보드

> **터무니없는 감 대신, 터무늬 있는 데이터**
> TERMUNI Real Estate Intelligence

🌐 **바로 보기: https://tjtjgml3377-cmd.github.io/**

아산시의 **인구(100m 격자)·일자리(국민연금 사업장)·실거래(매매·전월세)·상권(소상공인 상가)** 데이터를 하나로 엮은 대화형 부동산 대시보드입니다. 읍면동·단지 단위는 물론, **주소를 넣거나 지도를 클릭해 반경 100m~2km 안**을 바로 분석할 수 있습니다.

## 브이월드(VWorld) 인증키

이 공개판에는 **브이월드 인증키가 들어 있지 않습니다.** 그래서 기본 배경지도(CARTO·OSM)와 데이터 안의 주소 검색만 동작합니다.

브이월드 배경지도(일반·회색·야간·위성), 지적도, 전체 주소검색을 쓰려면:
1. [브이월드](https://www.vworld.kr)에서 인증키를 무료로 발급받습니다.
2. 대시보드의 **🎯 반경 분석 › 고급**에 키를 넣고 새로고침합니다. (키는 그 브라우저에만 저장됩니다)

### 꼭 알아 두실 점
- 공공데이터를 가공한 **참고 자료**이며 법적 효력이 없습니다. 계약·투자 전에는 등기부·현장·공식 통계를 반드시 확인하세요.
- 격자 인구는 5명 이하 칸이 0으로 공개된 것으로 추정되어, 인구가 적은 면 지역(송악·선장·도고·영인)은 과소 집계됩니다.
- 실거래·사업장에는 좌표가 없어 상가 좌표를 기준점으로 위치를 근사했습니다. 브이월드 지오코딩 대비 실측 오차(중앙값): A 42m · B 43m · C 194m.
- 아파트 가격 변화는 단순 중앙값보다 **동일단지 체인지수**로 보세요(신축 입주 등 구성 효과 제거).
- 자세한 내용은 대시보드의 **데이터·방법론** 화면에 있습니다.

## 폴더 구조

```
index.html          ← 완성된 대시보드 (이 파일 하나가 사이트 전체, 공개판)
src/                ← 대시보드 소스 (template.html + 화면별 JS)
data/data_gz.js     ← 가공된 데이터 (gzip + base64)
build/build.py      ← src + data + 라이브러리를 index.html 하나로 묶는 빌드 도구
pipeline/           ← 원자료 → 가공 데이터 스크립트 (원자료는 미포함, 참고용)
package.json        ← 빌드에 쓰는 라이브러리 목록 (echarts, leaflet)
```

## 다시 만들기 (수정 후 빌드)

```bash
npm install                    # echarts 5.5.1, leaflet 1.9.4
python build/build.py          # → index.html (공개판, 키 없음)

# 브이월드 키를 넣은 개인용 파일 (공개 저장소에 올리지 마세요)
VWORLD_KEY=발급받은키 python build/build.py --out dist/개인용_대시보드.html
```

`pipeline/` 스크립트는 원자료로 `data/data_gz.js`를 다시 만들 때 씁니다(Python 3, pandas·geopandas·pyproj). 원자료 폴더는 `RAW_DIR`, 작업 폴더는 `WORK_DIR` 환경변수로 지정하세요. 실행 순서: `build_master.py` → `geo_prep.py` → `pack.py`.
